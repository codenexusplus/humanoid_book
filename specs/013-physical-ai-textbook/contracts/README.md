# API Contracts

This directory will contain the OpenAPI (formerly Swagger) specifications for the FastAPI backend, defining all API endpoints, request/response schemas, and authentication methods. These contracts will serve as the definitive interface between the frontend (Docusaurus/React) and the backend services.

**Endpoints to be defined**:
*   Authentication (signup, signin, user profile)
*   Chatbot interaction (query, query with selection)
*   Content personalization (update settings, retrieve personalized content)
*   Content translation (retrieve translated content)
