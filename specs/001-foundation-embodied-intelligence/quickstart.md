# Quickstart

This document explains how to build and run the project.

## Prerequisites

- Node.js (version >= 20.0)
- npm or yarn

## Installation

1.  Navigate to the `my-website` directory:
    ```bash
    cd my-website
    ```
2.  Install the dependencies:
    ```bash
    npm install
    ```
    or
    ```bash
    yarn install
    ```

## Running the project

1.  Navigate to the `my-website` directory:
    ```bash
    cd my-website
    ```
2.  Start the development server:
    ```bash
    npm start
    ```
    or
    ```bash
    yarn start
    ```
    This will open the website in your browser at `http://localhost:3000`.

## Building the project

1.  Navigate to the `my-website` directory:
    ```bash
    cd my-website
    ```
2.  Build the project for production:
    ```bash
    npm run build
    ```
    or
    ```bash
    yarn build
    ```
    The build output will be in the `my-website/build` directory.
