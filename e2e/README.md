# End-to-End Tests

This directory will contain end-to-end tests for the Physical AI & Humanoid Robotics Textbook project.
These tests will cover core user flows such as:
- Book creation and deployment verification
- Chatbot interaction (querying, querying with selected text)
- User authentication (signup, signin)
- Content personalization
- Content translation

**Framework**: [To be decided, e.g., Playwright, Cypress]

**Initial Test File Structure**:
- `e2e/specs/`
  - `book_creation.spec.js`
  - `chatbot_interaction.spec.js`
  - `auth.spec.js`
  - `personalization.spec.js`
  - `translation.spec.js`
